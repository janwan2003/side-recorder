Record browser tests. Open your .side projects again.

Tapeline is a free browser extension that records your clicks and typing as test steps, replays them with automatic waits, and opens and saves .side project files. When a test is ready, export it to Playwright, Selenium WebDriver or Cypress code. No account, no server: your tests stay on your computer.

Everything a recorder needs, nothing to sign up for

Opens .side projects

Open the test projects your team already has. Steps, comments, suites and unknown fields are kept, so saving gives back the same file.

Records real actions

Clicks, typing, drop-downs, checkboxes and Enter become readable steps. Right-click any element to add an assertion.

Locators that survive

Prefers data-testid, ids and names over brittle paths, records several locators per element, and falls back to them when one breaks, with a warning.

Replays with waits

Waits for elements and retries assertions briefly, so tests do not fail because a page was still loading.

Control flow and variables

if, while, times, forEach, do/repeatIf, store, executeScript, run and dialog checks, as in your existing files.

Exports real code

Playwright Test, Selenium WebDriver for Python, Java and JavaScript, and Cypress. Free, with anything that cannot convert left as a clear TODO.

Questions

Is this Selenium IDE?
No. Tapeline is an independent project written from scratch. It reads and writes the same open .side JSON format, so projects move between the tools.
Why do I need it?
The old Selenium IDE browser extension was built on Manifest V2, which Chrome no longer runs. Tapeline is a Manifest V3 extension, so it installs in current Chrome.
Does it send my tests anywhere?
No. Tapeline makes no network requests of its own and has no account. Projects are kept in the extension's local storage and in files you save. See the privacy policy.
Which commands are supported?
Clicks, typing, keys, selections, mouse events, waits, assertions and verifications, variables, scripts, control flow, dialogs and running another test. Switching into iframes and between windows is not supported in replay yet; those steps are kept in the file and exported to code.
What does it cost?
Nothing. It is MIT-licensed open source.
